jQuery Library Inclusion

Scenario: Set up your workspace to use jQuery.

Objective & Task

Load the jQuery library and verify script execution.

  • Include jQuery using a CDN link.
  • Set up structure for a local copy fall-back (e.g. js/jquery.min.js).
  • Bonus: Append a <p> element that says "Hello World!" and print its content to the console using jQuery.

Inclusion Demo Canvas

Setup Syntax:
<!-- Option 1: Live CDN script (Linked in this head) -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<!-- Option 2: Local backup (Downloaded copy) -->
<script src="js/jquery.min.js"></script>

Handling User Interactions

Scenario: Toggle canvas styles dynamically based on click and double-click actions.

Objective & Task

Listen to complex mouse inputs (click and double-click) and update DOM styles.

  • Implement a button with id #colorBtn.
  • Implement a box container with id #colorBox (starts white).
  • Change the background of #colorBox to red when the button is clicked.
  • Change the background color back to white when double-clicked.

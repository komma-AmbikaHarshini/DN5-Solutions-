Use of Common Methods

Scenario: Toggle and animate element visibilities inside pages.

Objective & Task

Implement core jQuery animation and visibility transition methods.

  • Add exactly three <div> elements with the class .box.
  • Implement triggers for: .hide(), .show(), .fadeOut(), .fadeIn(), and .toggle().
  • Bonus: Chain transition methods together (e.g. .slideUp().delay(1000).slideDown()).

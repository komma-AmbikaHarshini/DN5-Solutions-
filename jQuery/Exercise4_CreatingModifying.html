Creating & Modifying Elements

Scenario: Manage dynamically generated lists of registrations.

Objective & Task

Insert and delete DOM nodes dynamically using jQuery creation syntax.

  • Create a form with a text input field and a submit button.
  • On submit, capture the input string value.
  • Create a new <li> element containing that value and append it to a <ul> list.
  • Include a "Remove All" button that clears the entire list structure.

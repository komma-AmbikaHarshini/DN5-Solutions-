Mouse and Keyboard Events

Scenario: Capture and visual-map mouse gestures and keyboard inputs.

Objective & Task

Bind events using standard jQuery mouse and keyboard helpers.

  • Create a <div> element with placeholder text.
  • Bind mouse helper triggers: .click(), .dblclick(), .mouseenter(), and .mouseleave().
  • Bind keyboard helper: .keypress() on an input field.
  • Ensure each action triggers a visible change on the interface (e.g. background color shifts, alerts, text streams).

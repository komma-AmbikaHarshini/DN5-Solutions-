Modern JavaScript Features

Scenario: Refactor code to be concise and maintainable.

Objective & Task

Refactor legacy approaches to use concise, standard ES6+ modern features.

  • Scoping via block-level let and read-only const.
  • Write cleaner functions using **default parameters** (e.g. category = "General").
  • Extract object parameters cleanly via **destructuring** (const { name, date } = event).
  • Utilize the **spread operator** ([...events]) to clone the list before applying filters to avoid modifying original array references.

Setting Up Bootstrap 5

Demonstration of link types (CDN and Local download/npm packages).

Exercise 1.1: CDN Link Integration

This entire page is linked live to Bootstrap v5.3.3 using the official jsDelivr CDN inside the <head>: 

<!-- Bootstrap 5 CSS CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap 5 JS Bundle CDN (including Popper) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
Status: CDN Link is active. Bootstrap typography, margins, and layouts are rendering.
Exercise 1.2: Local / NPM Project Setup

For production environments with offline requirements, you can install Bootstrap locally via npm or download the precompiled files directly:

# Install via npm package manager
npm install bootstrap

# Link offline files in your HTML template
<link rel="stylesheet" href="node_modules/bootstrap/dist/css/bootstrap.min.css">
<script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>

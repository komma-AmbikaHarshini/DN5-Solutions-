Customization with Sass

Overriding Bootstrap variables and recompiling stylesheets using Dart Sass and npm commands.

Exercise 19.1: Project Setup via NPM package.json

To recompile Bootstrap source stylesheets, we set up an npm package project that runs a local compilation script. In the project root folder, we initialized:

package.json (Scripts & Dependencies)
{
  "name": "bootstrap-sass-customization",
  "version": "1.0.0",
  "scripts": {
    "compile-sass": "sass custom.scss css/custom.bootstrap.css --watch"
  },
  "dependencies": {
    "bootstrap": "^5.3.3"
  },
  "devDependencies": {
    "sass": "^1.77.0"
  }
}

Run the installation and watch compilation script via: 

npm install
npm run compile-sass
Exercise 19.2: Overriding Variables in custom.scss

Inside the custom SCSS file, we override specific variables (like $primary and $border-radius) before importing Bootstrap's style core:

custom.scss
// 1. Override default variables BEFORE imports
$primary: #0ea5e9;           // Set primary brand theme to Sky Blue
$body-bg: #0f172a;           // Override background to slate dark
$border-radius-lg: 16px;     // Adjust border radius rounding

// 2. Import Bootstrap source files
@import "node_modules/bootstrap/scss/bootstrap";
Success: Recompiling maps the overridden Sass variables to utility values globally, updating primary backgrounds and borders automatically!
